## Licencias de las fuentes

Las dos familias de este sistema se sirven desde `fonts/` y son del proyecto:

- **Fraunces** — `fonts/Fraunces-600.woff2`. SIL Open Font License 1.1, texto completo en
  `OFL-fraunces.txt`. Se usa en 600, para títulos y nombres de producto.
- **IBM Plex Sans** — `fonts/IBMPlexSans-400-600.woff2`. SIL Open Font License 1.1, texto completo en
  `OFL-ibmplexsans.txt`. Se usa en 400 y 600, para todo lo demás, cifras incluidas.

Las dos se sirven **en local**: la primera pintada de la app no depende de ninguna CDN. Al copiar un
sistema o un artboard, los dos `.woff2` viajan con él; la licencia viaja también, en esta carpeta.
